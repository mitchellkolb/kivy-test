These are two applications I made after following through a tutorial series on how to use the Kivy UI python library. 


# Notes
- After having gone through the video tutorial I have determined that this UI library while open source and some-what useful is not the right one I think I should be learning because of two reasons.
    - Problems I have had getting it setup on my desktop linux system IDE and on the raspberry pi 3b+ which is the whole reason I went with this UI library to begin with. Kivy is supposed to have better touch support than PyQT which is the use case I have for my raspberry pi project.
    - I always leaned towards PyQT because it is used in the professional industry but never fully used it because it has a different development model and 160+ widgets to memorize which takes a lot of up front work to get past and I just wanted to get into the development of my project. I guess I will finally take the plunge once again into using PyQT and just get over the inital learning hump.
